# Core / Field Guide

Учебный сайт-каталог интернет-эстетик на JavaScript. Пользователь может изучать направления, искать их по названию и категории, создать аккаунт и предложить новое направление.

## Возможности проекта

- Главная страница и каталог Core-направлений.
- Поиск по названию, категории и короткому описанию.
- Отдельная страница каждого направления с мотивами и цветовой палитрой.
- Регистрация, вход, выход и хранение пользователей в MongoDB.
- Пароли хранятся в виде хешей с индивидуальной солью.
- Добавление направления доступно после входа.
- Сессии пользователей хранятся в MongoDB.
- Серверные шаблоны EJS и адаптивная вёрстка.

## Требования

- Node.js 20 или новее и npm.
- MongoDB Community Server на этом компьютере либо строка подключения к MongoDB Atlas.

## Запуск

### Быстрый запуск в Windows

1. Установите Node.js LTS и MongoDB Community Server. Во время установки MongoDB оставьте включённым запуск как службы Windows.
2. Распакуйте архив релиза в обычную папку.
3. Дважды щёлкните `run-local.bat`. При первом запуске он создаст локальный `.env`, установит пакеты, заполнит пустую базу и откроет сайт в браузере.
4. Оставьте открытым окно сервера. Чтобы остановить сайт, нажмите `Ctrl+C` в этом окне.

Сайт будет доступен по адресу [http://localhost:3000](http://localhost:3000). Если MongoDB не запущена, откройте `services.msc`, запустите службу **MongoDB**, затем повторно запустите файл.

### Ручной запуск для разработки

1. Установите Node.js с npm и MongoDB Community Server.
2. В терминале из папки проекта установите пакеты:

   ```sh
   npm install
   ```

3. Создайте файл `.env` на основе `.env.example`. Для локального MongoDB можно оставить строку подключения по умолчанию. Замените `SESSION_SECRET` на длинную случайную строку.
4. Заполните каталог начальными данными:

   ```sh
   npm run seed
   ```

5. Запустите приложение:

   ```sh
   npm start
   ```

6. Откройте [http://localhost:3000](http://localhost:3000).

Для разработки с автоматическим перезапуском используйте `npm run dev`.

## Структура

- `app.js` — настройка Express, сессий, подключения к MongoDB и маршрутов.
- `routes/` — каталог и регистрация/вход.
- `models/` — модели MongoDB для направлений и пользователей.
- `middleware/` — текущий пользователь и проверка входа.
- `views/` — EJS-шаблоны страниц.
- `public/css/` — стили сайта.
- `scripts/seed.js` — начальное заполнение каталога.

## Основные адреса

- `/` — главная.
- `/core` — каталог и поиск.
- `/core/:slug` — описание направления.
- `/core/new` — форма добавления (после входа).
- `/register` и `/login` — аккаунт.
